# Testes manuais do Paulista Verde

Abra o site publicado e confira:

- [ ] A página abre no endereço HTTPS do GitHub Pages.
- [ ] Os estilos e os botões carregam normalmente.
- [ ] A pesquisa por `Coentro` encontra o exemplo de coentro.
- [ ] A lista muda ao escolher `Hortaliças`.
- [ ] A seleção de espécie preenche os meses sugeridos.
- [ ] Um cadastro sem ponto mostra uma mensagem explicando o que falta.
- [ ] Ao marcar um ponto, autorizar o cadastro e enviar, a planta aparece na lista.
- [ ] Recarregar a página mantém o cadastro **local** no mesmo navegador.
- [ ] Os locais com o aviso **EXEMPLO FICTÍCIO** aparecem como demonstração.
- [ ] O navegador solicita permissão quando a pessoa clica no botão de GPS.
- [ ] Se a conexão ao mapa falhar, a lista de plantas continua disponível.
- [ ] Se configurar o Supabase, teste se o cadastro aparece em um **segundo navegador**.

Nota: GPS exige permissão e HTTPS/localhost. O mapa e fontes externas precisam de internet. O Supabase é opcional, mas necessário para compartilhamento entre dispositivos.
